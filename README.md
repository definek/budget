# 식당 창업예산 관리

식당 창업(오픈) 준비 과정의 **초기비용**을 카테고리별로 기록·관리하는 웹앱입니다.
운영예산이 아닌 창업/오픈 초기비용 전용입니다.

`index.html` 파일 하나로 동작합니다. 브라우저로 열기만 하면 바로 사용할 수 있고,
별도의 서버나 빌드 과정이 없습니다.

## 사용법

```
index.html 을 브라우저에서 열기
```

## 기능

### 지출 내역 관리 (CRUD)
- 날짜 · 카테고리 · 항목명 · 금액 · 메모 입력
- 각 내역의 수정 / 삭제, 삭제 시 확인 다이얼로그
- 최신 날짜순 정렬, 카테고리별 필터

### 카테고리 관리
기본 카테고리 8종을 기본 제공합니다.

| 카테고리 |
| --- |
| 임차보증금/권리금 |
| 인테리어비 |
| 주방기기·설비비 |
| 가구·집기비 |
| 초도 식자재비 |
| 인허가·등록비 |
| 오픈 마케팅비 |
| 예비비 |

- 카테고리 직접 추가 / 삭제 (중복 이름 방지)
- 카테고리 삭제 시 연결된 내역 건수·금액을 먼저 안내

### 금액 입력
- 숫자만 입력, 천 단위 콤마 자동 포맷
- 원화(₩) 기호 상시 표시
- `+1만 / +10만 / +100만 / +1천만` 빠른 입력 버튼

### 집계
- 전체 창업비용 합계
- 카테고리별 합계 및 비중
- 카테고리별 예산 설정 시 진행률 표시, 초과분은 빨간색으로 강조
- 예산 · 지출 · 잔여(초과) 요약

## 데이터

모든 데이터는 JSON 구조로 브라우저 **localStorage**(키: `restaurant-startup-budget-v1`)에
저장됩니다. 서버로 전송되지 않습니다.

```json
{
  "categories": [
    { "id": "cat1", "name": "임차보증금/권리금", "budget": 60000000 }
  ],
  "expenses": [
    {
      "id": "exp1",
      "categoryId": "cat1",
      "date": "2026-08-15",
      "title": "보증금 계약금",
      "amount": 5000000,
      "memo": ""
    }
  ]
}
```

`budget`은 카테고리별 예산 설정 시에만 사용되는 선택 필드이며, 미설정 시 `0`입니다.

### 내보내기 / 불러오기

`카테고리 관리` 화면에서 데이터를 주고받을 수 있습니다.

- **JSON 내보내기** — 현재 데이터 전체를 클립보드에 복사 (백업용)
- **JSON 불러오기** — `.json` 파일을 선택해 데이터를 복원. 불러오기 전 카테고리·내역
  건수를 확인하는 다이얼로그가 뜨며, 기존 데이터는 대체됩니다.

저장소의 [`data.json`](data.json)은 바로 불러와 볼 수 있는 **샘플 데이터**입니다
(내역 7건 / 총 ₩101,850,000, 예산 ₩126,000,000). 구조를 확인하거나 화면을
미리 살펴볼 때 사용하세요.

불러온 JSON은 항상 검증을 거칩니다. 형식이 깨졌거나 알 수 없는 필드가 있으면
해당 항목을 버리거나 기본값으로 되돌리고, 파싱 자체가 불가능하면 기존 데이터를
그대로 유지합니다.

> 브라우저 데이터를 삭제하거나 시크릿 모드를 종료하면 기록이 사라집니다.
> 중요한 데이터는 JSON 내보내기로 백업해 두세요.

## 기술

- 단일 HTML 파일 (HTML + CSS + Vanilla JS)
- 외부 프레임워크·라이브러리 없음, 네트워크 요청 없음
- 토스 디자인 시스템 스타일: 포인트 컬러 `#3182F6`, 카드형 레이아웃,
  큰 radius(12~20px), 은은한 그림자, 넉넉한 여백
- 모바일 퍼스트 반응형, 다크 모드 지원 (`prefers-color-scheme`)
